# Titanic Dataset – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic passenger dataset using Python. The main objective is to analyse passenger information, calculate important statistics, identify trends and patterns, and discover useful insights through data visualization.

## Dataset
- Dataset Name: Titanic Dataset
- Source: [Kaggle Titanic Dataset](https://github.com/datasciencedojo/datasets)
- Total Records: 891 passengers
- Data Type: Structured Dataset

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Steps Performed

1. **Data Loading:** Loaded the Titanic dataset using Pandas.
2. **Data Cleaning:** Removed duplicate records and handled missing values.
3. **Data Exploration:** Checked dataset information, columns and statistical summaries.
4. **Statistical Analysis:** Calculated average age, average fare, survival count and survival percentage.
5. **Data Visualization:** Created five charts to understand the dataset.
6. **Insight Generation:** Identified useful trends, patterns and anomalies.

## Visualizations Created
1. Survival Count – Shows the number of passengers who survived and did not survive.
2. Survival by Gender – Compares survival rates of male and female passengers.
3. Survival by Passenger Class – Shows survival rates across different passenger classes.
4. Age Distribution – Displays the age distribution of passengers.
5. Ticket Fare Distribution – Compares ticket fares across passenger classes.

## Key Insights

1. Most passengers did not survive the Titanic accident.
2. Female passengers had a higher survival rate than male passengers.
3. First-class passengers had a higher survival rate than third-class passengers.
4. Most passengers belonged to the young-adult age group.
5. First-class passengers generally paid higher ticket fares than passengers in other classes.

## Conclusion
Exploratory Data Analysis helped in understanding the Titanic passenger dataset. Through statistical analysis and data visualization, important trends and patterns were identified. The analysis showed that gender and passenger class were strongly associated with survival. This project provided practical experience in Python-based data analysis and visualization.
